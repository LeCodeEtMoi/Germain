// Les fichiers CSS

Le style est réparti en quatre fichiers à placer dans src/styles/, plus le bloc <style> de chaque page. Chacun a un rôle précis, pour éviter qu’un style en écrase un autre.

theme.css Toutes les pages
Le socle commun. Il définit les 7 couleurs (variables CSS), la police du texte (Inter), la classe .righteous pour les titres et le contour de focus au clavier. Rien d’autre : c’est ce qui garantit que chaque page a la même identité.
outils.css Accueil (composant Explication)
Le carrousel Leçon / Exercice / Quiz : grande carte lavande en deux colonnes (illustration + texte), flèches rondes (.arrow), petits points de navigation (.point). Passe sur une seule colonne sur mobile.
apropos.css Page À propos (composant About)
La liste de questions à gauche (.apropos__onglets, l’onglet actif a un trait violet) et le texte à droite (.apropos__panneau), avec portrait optionnel et une petite animation d’apparition. Les noms suivent la convention apropos__élément pour ne jamais entrer en conflit avec d’autres styles.
exercice.css Tous les exercices
Tout l’habillage des exercices : énoncé, cartes de données, champs, choix (boutons radio), boutons, aide à la saisie, formules, et les trois retours après validation (réussite, erreur, incompris). Importé par chaque page ex_N_T.astro, jamais par les composants .tsx.
Bloc <style> de chaque page Une seule page
La mise en page propre à la page (titre d’introduction, rythme vertical --espace, panneaux). Les boutons en pilule sont redéfinis dans chaque page qui les utilise.

// Couleurs

Définies une fois dans theme.css, utilisées partout avec var(--nom). On ne tape jamais un code hexadécimal à la main dans une page.

Aa

--violet #6528d9

Couleur principale : boutons, liens, titres de section, bordures des champs.

Aa

--violet-profond #2a1466

Fonds sombres (panneaux, message de réussite) et survol des boutons violets.

Aa

--lavande #a28bfa

Accent doux, pour les détails décoratifs.

Aa

--lavande-pale #efeaff

Fonds de panneaux, de cartes de données et de champs mis en avant.

Aa

--papier #faf9ff

Fond très clair des sections en alternance et des survols.

Aa

--encre #1f1a3d

Texte courant et titres (un noir légèrement violet).

Aa

--craie #ffd25e

Touche de jaune : « X », signes // sur fond sombre, survol des boutons clairs.

Pour rappel, --primary-color reprend --violet : le pied de page l’utilise.

// Typographie

Titres : Righteous

// Le titre de section

Classe .righteous. Chaque titre commence par la signature // en violet (ou en jaune craie sur fond sombre), marquée aria-hidden pour les lecteurs d’écran.

Texte : Inter

Les mathématiques permettent de réaliser d’innombrables choses : musique, météorologie, cryptographie, médecine, sport…

Défini sur body : taille de lecture 1,1 à 1,2 rem, interligne ample, lignes limitées à environ 55 caractères.

Focus au clavier. Tout élément atteint avec Tab reçoit un contour violet de 3 px (:focus-visible dans theme.css). Essayez : ce lien.

// Boutons et commandes

Tous les boutons sont en pilule (border-radius: 999px) et changent de couleur au survol.

Action principale. Survol : violet profond. .bouton-principal

Action secondaire, sur fond clair. Survol : fond lavande pâle. .bouton-contour

Bouton blanc pour les panneaux violets. Survol : jaune craie. .bouton-clair

Commandes du carrousel (outils.css) : flèches rondes et points ; le point actif est plein.

// Panneaux

Des blocs aux coins très arrondis (1,5 rem), en deux tons : clair pour l’information, sombre pour l’appel à l’action.

// Panneau clair

Fond --lavande-pale, texte --encre.

// Panneau sombre

Fond --violet-profond, signe // en --craie.

Les classes de exercice.css

.exercice
Conteneur de l’exercice (largeur maximale 46 rem).
.exercice-titre
Titre « // Énoncé » en Righteous.
.exercice-enonce / .exercice-formule
Texte de l’énoncé et encadré lavande pour une formule.
.exercice-donnees / .exercice-donnee
Grille de cartes « libellé : valeur » (points, vecteurs).
.exercice-champ, .exercice-label, .exercice-aide
Champ texte à bordure violette, son libellé et son aide.
.exercice-choix
Choix unique : chaque option devient une carte, violette quand elle est cochée.
.exercice-touches / .exercice-touche
Petits boutons d’aide à la saisie (√, ln, sin…).
.exercice-bouton--principal / --secondaire
Valider (plein) et Nouvel exercice (contour).
.exercice-retour--correct / --faux / --incompris
Message de réussite (violet profond), d’erreur (rose) et d’incompréhension (lavande).
.exercice-correction, .exercice-astuce
Étapes numérotées de la correction et encadré de conseils.
