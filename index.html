// Germain open source

Germain est un projet open source : tout le monde peut contribuer à son développement. Plus nous avons de retours, plus nous pouvons améliorer Germain et offrir une meilleure immersion dans le pays des maths.

Voir le projet sur GitHub

// Un coup de pouce ?

Un peu de temps suffit. Vous pouvez par exemple :

  • relire une leçon ou un exercice ;
  • partager votre expérience des maths dans votre métier ;
  • nous faire découvrir un domaine précis qui vous passionne ;
  • proposer une idée de leçon ou d'exercice.

Toute aide compte pour que le projet grandisse et s'améliore.
